B("PL.B.PERIOD") == Read COMPANY<134> "PLPER" // "This Period P/L"
					if that's empty, then read COMPANY<10> "GLPER" // "This Period G/L"

That grabs you the CURRENT period

If <154> "Future" is empty, then just return (returning VALUE)
	otherwise, read "No. of Financial Periods" from COMPANY<11> "GLPRDS" // No. of Financial Pds
	Value += 1
	if Value > No. of Financial Periods
		Value = 1 // and there's the wrap-around
		
	So if we were in say February, Value would be 11 - you'd add one, find yourself at 12, and not need to wrap-around because March is the 12th period in this financial year.
	
	If, however, you were in March, Value would equal 12 - you'd add one, compare that to GLPRDS (12), find that 13 > 12, and set Value to 1.
